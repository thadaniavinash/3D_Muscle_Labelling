# Model Asset

Place the downloaded Sketchfab model here as:

```text
assets/male-full-body-ecorche.glb
```

The phase 1 prototype will automatically load that file when present. If it is
missing, the app falls back to a simplified proxy body so the floating label and
arrow anchoring can still be tested.
